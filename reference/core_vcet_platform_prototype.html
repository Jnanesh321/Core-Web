Regional Club Inspiration Matrix

1. SOSC (Sahyadri Open Source Community)

Inspired our open-source transparency: live GitHub repo links on every project card, contributor attribution, and community-owned events.

2. FiniteLoop Club (NMAMIT, Nitte)

Inspired our structured project rigor, domain tracks (Web, AI/ML, Systems), peer mentorship hierarchy, and polished dark-mode showcase cards.

3. DevNation (AJIET, Mangaluru)

Inspired our high-energy flagship hackathon/bootcamp presentation (CoRE Unbounded & CoRE Unleashed) and accessible student onboarding.
